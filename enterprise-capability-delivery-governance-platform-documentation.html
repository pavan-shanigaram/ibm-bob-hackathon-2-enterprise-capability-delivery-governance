Use Cases

Team & Organisational Management

Teams
Enterprise Team Administration
  • Create and manage enterprise teams with leads
  • View squad count and headcount per team
  • Edit team ownership and description
  • Delete teams (admin only)
Squads
Agile Squad Management
  • Create scrum squads under a team
  • Assign scrum master to a squad
  • Set sprint capacity in story points
  • Add and remove squad members with roles
Employees
Employee Directory & Profiling
  • Browse employees with team and role filters
  • View employee utilisation percentage
  • Add skills with proficiency levels
  • Track squad membership count
Employees
Resource Allocation Monitoring
  • Record allocation periods per employee
  • Detect over-allocation automatically
  • View alerts for employees exceeding 100%
  • Filter allocations by employee

Project Delivery & Governance

Projects
Project Portfolio Management
  • Create projects with status and priority
  • Track health indicator (Green / Amber / Red)
  • Assign squads and employees to projects
  • Filter projects by status, priority, owner team
Project Hub
Team & Squad Breakdown per Project
  • View all teams involved in a project
  • See squads per team with member drill-down
  • Expand squads to view individual members and roles
  • Visual BLOCKED badge on teams with active blockers
Project Hub
Workflow Timeline Management
  • Define per-team phases for any project
  • Assign phases even if no squad is assigned yet
  • Track phase status: Not Started / In Progress / Done / Blocked
  • Set planned start and end dates per phase
Project Hub
Inter-Team Dependency Tracking
  • Record dependencies between any two teams in the system
  • Categorise as Blocker / Parallel / Sequential
  • Highlight blocker rows in red with left-border indicator
  • Mark dependencies as Resolved when cleared

Capability & Compliance

Capabilities
Capability Matrix & Gap Analysis
  • View employee-skill proficiency matrix
  • Identify skill gaps against project requirements
  • Track Beginner / Intermediate / Expert / Lead levels
  • Create new skills in the master catalogue
Authorizations
System Access Compliance
  • Grant access to: GitHub, AzureDevOps, SAP, Salesforce, Production
  • Track expiry dates and auto-flag expired access
  • Generate compliance report across systems and teams
  • Status: Compliant / Expired / PendingReview / Revoked
Metrics
Delivery Performance Tracking
  • Record sprint metrics per squad and project
  • Computed delivery score per sprint
  • View velocity trend over last N sprints
  • Track cycle time, lead time, defect leakage
Reports
Executive Reporting & Insights
  • Executive dashboard with top-level KPIs
  • Skill gap report by project
  • Capacity risk — over-allocated teams
  • Delivery bottleneck analysis

AI Intelligence (IBM watsonx.ai)

AI
Skill Gap Narrative
  • Analyse missing skills for a specific project
  • Generate natural-language hiring recommendations
  • Powered by Granite 3.3 8B Instruct
AI
Delivery Coach
  • Analyse sprint metrics for a squad
  • Generate sprint improvement suggestions
  • AI-driven velocity and quality guidance
AI
Risk Summary

  • Generate board-ready risk narrative

AI

Role-Based Access Control

platform_admin
  • Full CRUD on all entities
  • Delete teams, squads, employees
  • Manage authorizations
  • Manage phases and dependencies
team_lead
  • Manage own team's squads
  • Create and update projects
  • Assign squads and employees
  • Manage phases and dependencies
scrum_master
  • Update own squad
  • Add/remove squad members
  • Record sprint metrics
  • Assign employees to projects
employee
  • Read-only access to all data
  • View own profile
  • Add own skills
executive
  • Read-only dashboards
  • View all reports
  • Access AI insights
security_admin
  • Manage system authorizations
  • Review compliance records
  • Trigger expiry checks

Quick Start

git clone https://github.com/pavan-shanigaram/ibm-bob-hackathon-2-enterprise-capability-delivery-governance.git
cd ibm-bob-hackathon-2-enterprise-capability-delivery-governance
cp .env.example .env
# Clear AUTH0_DOMAIN= for demo mode, add DATABASE_URL for MySQL
docker compose up --build -d
Demo Mode: Set AUTH0_DOMAIN= (empty) in .env to activate demo mode — all API calls are authenticated as platform_admin without requiring a real Auth0 token.
